## How to sign

Signing is handled automatically when You open a pull request. The CLA assistant
bot will post a comment on Your first pull request asking You to agree to this
Agreement. To sign, post a pull request comment with exactly the following text:

```text
I have read the CLA Document and I hereby sign the CLA
```

Your signature (your GitHub username and the pull request reference) is recorded
in `.cla/signatures.json` in this repository. You only need to sign once;
subsequent pull requests are recognized automatically.
